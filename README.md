By using this OS, You must agree to not leak the ISO anywhere public. This repo is only for Insiders and developers.

# How to build ISO

On windows you need to install WSL (Windows subsystem for Linux), Then go into the repo folder and run this command `make iso`, You will see xorriso running and compiling the ISO for you.

# System Requirements 

**512MB RAM** For all the resources to load correctly
**1-2 CPU CORES** For good performance
**600MB ROM (STORAGE)** Installation
**IDE DISK AND LEGACY BIOS** I will add support for NVME and SATA later
